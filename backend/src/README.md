# Backend Structure

## Dossiers:
- `/src/routes` - Définition des endpoints
- `/src/controllers` - Logique requête/réponse
- `/src/services` - Logique métier
- `/src/models` - Modèles Sequelize
- `/src/middleware` - Authentification, validation
- `/src/config` - Configuration DB, Keycloak
- `/src/utils` - Utilitaires (email, SMS)
- `/src/migrations` - Migrations DB
